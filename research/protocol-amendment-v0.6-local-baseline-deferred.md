# Run-scope amendment: local baseline deferred

The local Qwen2.5-Coder baseline is deferred from this budget-constrained run.
The study's immediate purpose is to compare hosted model behavior under the
same temperature-controlled protocol. The local baseline remains a useful
future reproducibility and cost reference, but is not required for the hosted
model comparison and would add cells without testing a distinct remote route.

The local model is therefore not silently treated as missing data: it is
explicitly deferred and can be run later as a separate follow-up study.
